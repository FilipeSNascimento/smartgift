🎨 SmartGift — Protótipos em Camadas Editáveis para o Figma

Todas as 5 telas abaixo foram construídas em SVG Vetorial Estruturado com grupos nomeados (#Clash-Top-HUD, #Instagram-Stories-Carousel, #Deck-Card-1-Legendary, etc.). Para editar qualquer tela no seu arquivo do Figma, basta arrastar os arquivos .svg da pasta figma-prototypes/ para dentro do Figma!

📐 Abrir Arquivo Criado no Seu Figma ↗
1. Abra o arquivo criado no seu Figma Clique no botão verde acima para abrir SmartGift — Protótipos Mobile & Web no seu time do Figma.
2. Arraste os 5 arquivos .svg ou copie Arraste os arquivos da pasta figma-prototypes/ direto para o canvas do Figma (ou clique em "Baixar SVG").
3. Edite 100% das camadas livremente Cada texto, card de raridade, botão 3D, barra de vaquinha e ícone vira uma camada nativa editável no Figma.
